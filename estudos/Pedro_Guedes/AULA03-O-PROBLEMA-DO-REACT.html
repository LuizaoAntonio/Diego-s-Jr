    Registro dos experimentos

    1. Sem chamar desenhar() depois do clique, o vetor recebe a tarefa, mas a lista e o contador ficam desatualizados. Conferir o vetor no console prova que o dado mudou.
    2. O campo digitado dentro de um item desaparece ao adicionar outra tarefa, porque innerHTML = "" remove a lista e seus campos antes de desenhá-los de novo.
    3. Para mostrar total, tarefas feitas e aviso de lista vazia, a função de desenho precisa atualizar quatro partes: a lista, o contador, a contagem de feitas e o aviso.
    4. Se o id da lista mudar apenas no HTML, getElementById("lista") retorna null. O erro aparece no console quando o script tenta acessar innerHTML durante o desenho inicial.

    O experimento mais incômodo é perder o que foi digitado: a tela apaga uma informação do usuário mesmo que ela ainda não tenha sido salva.
